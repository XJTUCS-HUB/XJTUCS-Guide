## 3.1 存储器概述

### 3.1.1 存储器分类

如果按照在**计算机系统**中的作用分类：
- 内部存储器（主机内）    Cache和主存
- 外部存储器（主机外）    硬盘等等
- 控制存储器（CPU内）

按**存储介质**分类：半导体存储器（体积小速度快）；磁表面存储器；光盘存储器

按**存取方式**分类：
1. RAM 
	可读可写，广泛用于主存
	RAM又可以分为：
	1. SRAM 一般用来做Cache，集成度低、功耗大，无需刷新电路
	2. DRAM 一般用来做大容量主存，利用电容存储电荷，需要定时刷新
	3. NVRAM 由SRAM和EEPROM共同构成，具备掉电保护
2. ROM 只读存储器，断电后数据不丢失，常用于存储系统固件BIOS
	- MROM 掩膜ROM
	- PROM 可编程ROM
	- EPROM 紫外线擦除ROM
	- EEPROM 电可擦除ROM
	- Flash Memory 闪存，兼具ROM的非易失性和RAM的快速存取特性
3. SAM 顺序存取存储器，如磁带，存取时间与物理位置相关
4. DAM 直接存取存储器，如磁盘，兼具直接定位与顺序寻址
5. AM / CAM 相联存储器，按内容检索，常用于TLB和Cache的行地址匹配

### 3.1.3 存储系统工作原理

Cache-主存层：
	基于程序局部性原理，时间局部性与空间局部性。将频繁使用的指令和数据存放在Cache中，加快CPU访存速度，寻址空间对程序员而言仍为主存空间。
主存-辅存层：
	广泛采用**虚拟存储技术**，即将主存与辅存的一部份通过软硬结合的技术组成虚拟存储器，程序运行时，再由软、硬件自动完成虚拟地址空间与主存实际物理空间的转换。

#### 半导体芯片的地址译码
**线选法**：地址译码直接选中一个存储单元的全部位。如果n位地址，需要$2^n$根译码线和驱动器（适合高速小容量存储器）

**重合法**：把地址分成行和列，这样只需要找行和列的重合点就可以了，大大减少译码输入。

如果n位地址，需要$2^{n/2}+2^{n/2}$根译码线和驱动器

### 3.2.2 主存的性能指标

通常`存取周期=存取时间+恢复时间`
存储器带宽决定了单位时间内存储器存取的信息量，=存取周期的倒数

#### DRAM的定期刷新

因为电容漏电，所以断路时电容电荷也会慢慢泄露，所以必须进行**刷新**操作

1. 集中式刷新
	集中安排一段时间对**全部**存储元逐行刷新（在最大刷新间隔内）
	![第3章 存储器__5](https://pub-e7c93c0b727d457c895b016a26707158.r2.dev/2026/10/%E7%AC%AC3%E7%AB%A0%20%E5%AD%98%E5%82%A8%E5%99%A8__5.png)
	刷新期间不能访存，形成**死时间**
2. 分散式刷新
	每一个读/写周期之后紧接一个刷新周期，对存储矩阵中的**一行**进行刷新
	![第3章 存储器__6](https://pub-e7c93c0b727d457c895b016a26707158.r2.dev/2026/10/%E7%AC%AC3%E7%AB%A0%20%E5%AD%98%E5%82%A8%E5%99%A8__6.png)
	CPU访存时间延长一倍，且存在多余的访存操作
3. 异步式刷新
	在最大刷新时间间隔内，刷新周期平均分散，刷新**全部**存储元
	![第3章 存储器__7](https://pub-e7c93c0b727d457c895b016a26707158.r2.dev/2026/10/%E7%AC%AC3%E7%AB%A0%20%E5%AD%98%E5%82%A8%E5%99%A8__7.png)
	集合前两者的优点，但是比较复杂，需要较多的存储器外围电路支持

#### 存储器和CPU连接
- 存储器和CPU一般通过总线连接
==这一段很重要，需要结合ppt上的例子进行理解==

连接时四类线：
1. 地址线：低位地址直接接存储芯片内部地址端，高位地址用来做片选译码
2. 数据线：做位扩展
3. 读写控制线：CPU 读写控制端对应连接芯片的读使能 $\overline{OE}$ 和写使能 $\overline{WE}$
4. 片选控制线：一般用 74LS138 译码器对高位地址译码，结合 CPU 的访存使能信号 $\overline{MREQ}$ 产生片选信号 $\overline{CS}$

### 8086 对存储器的读取

主存使用小端方式编址，按字节编址但可以按字访问。

8086 采用奇偶分体结构：
- 偶地址存储体：数据线接 $D_7 \sim D_0$，由最低位地址 $A_0 = 0$ 选中
- 奇地址存储体：数据线接 $D_{15} \sim D_8$，由高位字节允许信号 $\overline{BHE} = 0$ 选中

访存周期情况：
- 访问起始为偶地址的字：$A_0=0$ 且 $\overline{BHE}=0$，一个总线周期就能读出
- 访问起始为奇地址的字：需要两个总线周期，先读奇地址字节，再读偶地址字节拼成一个字

## 3.4 Cache

### 3.4.1 Cache工作原理

存取速度快，容量小。Cache的命中率越高，访存的时延越低。
常用计算指标：
- 命中率：$h = \frac{N_c}{N_c + N_m}$，其中 $N_c$ 为命中 Cache 次数，$N_m$ 为访问主存次数
- 平均访存时间：$T_a = h \cdot t_c + (1-h) \cdot t_m$
- 访问效率：$e = \frac{t_c}{T_a}$

### 3.4.2 cache的设计要素

地址映射和变换

局部性原理：
cache和主存之间用块为单位交换

![第3章 存储器__17](https://pub-e7c93c0b727d457c895b016a26707158.r2.dev/2026/11/%E7%AC%AC3%E7%AB%A0%20%E5%AD%98%E5%82%A8%E5%99%A8__17.png)

主存和cache之间有三种映射方式：
1. **直接映射**
2. **全相联映射**
3. **组相联映射**

#### 替换策略
Cache 满了需要换出块时的算法：
- RAND：随机替换
- FIFO：先进先出，没考虑局部性
- LRU：最常用
- LFU：最不经常使用

#### 写策略
- 写命中时：
	- 全写法 ：同时写 Cache 和主存，简单安全但写操作慢
	- 写回法：只写 Cache 并打上脏标记，该行被换出时才写回主存，速度快
- 写未命中时：
	- 写分配 ：把对应主存块调入 Cache 再写，通常和写回法搭配
	- 非写分配：直接写主存不调入 Cache，通常和全写法搭配

### 3.5.3 磁盘阵列

RAID 冗余磁盘阵列 Redundant Array of Independent Disks
将多个独立磁盘组合成一个逻辑磁盘，兼顾存储性能与可靠性

了解即可：
- RAID 0：数据分散存于多个磁盘并行读写，速度最快，容量利用率100%，但任一盘损坏则数据全部丢失
- RAID 1：镜像备份，数据完全复制到另一组磁盘，可靠性高，容量利用率仅50%
- RAID 2：海明码纠错，按位交叉存取，实现复杂（很少使用）
- RAID 3：位交叉奇偶校验，数据按位或字节分散，专用一块盘存放奇偶校验信息
- RAID 4：块交叉奇偶校验，数据按块分散，同样专用校验盘，写操作存在校验盘瓶颈（很少使用）
- RAID 5：分布式奇偶校验，校验信息轮流分布在各磁盘上，兼顾性能与可靠性，应用最广
- RAID 6：双重校验，可同时容忍两块盘失效

重点掌握 RAID 0、1、5 的原理与容量利用率计算

### 3.5.4 其他辅助存储器

- 光盘存储器：利用激光在盘片表面读写信息
- 磁带存储器：顺序存取，常用的备份级离线存储器
- 固态硬盘 SSD：由 Flash Memory 芯片构成，无机械部件，寿命受闪存擦写次数限制
- U盘：Flash Memory 构成的便携式存储设备，即插即用
