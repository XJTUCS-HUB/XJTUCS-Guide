## Background
一对基址寄存器和限长寄存器定义了逻辑地址空间

- 在源程序中：符号地址  
- 编译后：相对地址  
- 链接或加载后：绝对地址

在什么时候进行地址Binding呢？编译时（少），加载时，执行时

在编译时和加载时地址绑定方案中，逻辑和物理地址是相同的；逻辑（虚拟）地址和物理地址在执行时地址绑定方案中是不同的

## 连续分配

一般将用户进程保存在高地址内存中，常驻操作系统保存在低地址内存

### 固定分区

操作系统保留一个表，指示内存的哪些部分可用，哪些部分已被占用

### 动态分区分配
当一个进程到达时，系统会从足够大的空闲内存块中为其分配内存，也因此会产生Hole

有四种分配策略；
- First-fit
- Next-fit
- Best-fit
- Worst-fit

## Paging
减少外部碎片化的另一个方法，允许进程的物理地址空间可以是不连续的

### 基本思想
- **物理内存划分**：将物理内存分成固定大小的块，称为Frame
- **逻辑内存划分**：将逻辑地址空间也分成相同大小的块，称为页
- **地址转换**：通过**页表 Page Table**将逻辑页映射到物理页框

### 地址结构
CPU生成的逻辑地址由两部分组成：
- **页号 $p$**：用于作为页表的索引，查找该页对应的物理内存页框号
- **页内偏移 $d$**：与页框基地址组合，形成送入内存单元的实际物理地址

彻底避免了外部碎片，但仍然存在**内部碎片**

### TLB
两次访存太慢了，通过在中间载入类似Cache的结构解决，这种缓存被称为TLB

![Chapter 8 Main Memory__4](https://pub-e7c93c0b727d457c895b016a26707158.r2.dev/2026/11/Chapter%208%20Main%20Memory__4.png)

关联寄存器查询时间：$\varepsilon$
$Hit\ ratio = \alpha$

有效访问时间EAT的计算
$$ \begin{aligned} \text{EAT} &= (1 + \varepsilon)\alpha + (2 + \varepsilon)(1 - \alpha) \\ &= 2 + \varepsilon - \alpha \end{aligned} $$

### Structure of the Page Table

现代计算机逻辑地址空间非常庞大，传统的单级线性页表会占用过多连续内存，因此需要优化页表结构

#### 分级页表
逻辑地址空间变大的同时会带来页表的臃肿，所以采用多级页表

多级页表会影响性能，导致访存效率下降，k级页表平均时间复杂度是O(k)

以两级页表为例，逻辑地址被划分为外层页号 $p_1$、内层页号 $p_2$ 和页内偏移 $d$

 **缺点**：每一级间接引用都会多一次内存访问，访存延迟随级数增加而线性上升，极度依赖 TLB 命中率

#### 哈希页表
核心是散列查找，平均时间复杂度是O(1)

- **结构**：哈希表的每一个条目都包含一个链表，链表中的节点保存三个字段：虚拟页号、映射的物理页框号、指向下一节点的指针。
- **工作机制**：将虚拟地址中的虚拟页号代入哈希函数，定位到哈希表对应的链表


#### 倒置页表
反转映射关系，面向物理内存而非逻辑地址空间建立页表

页表大小正比于 物理内存，空间开销很小，但是性能会较低（性能换空间）

## Segmentation 分段
分页没有逻辑性，所以我们提出了分段

提出分页管理的目的是为了提高内存空间的利用率；提出分段管理的目的除了也可以提高内存空间的利用率（相对分区管理而言）外，主要是为了更好地实现程序的共享和动态链接，并方便用户编程

还可以设置保护位
![Chapter 8 Main Memory__8](https://pub-e7c93c0b727d457c895b016a26707158.r2.dev/2026/11/Chapter%208%20Main%20Memory__8.png)

页表单元类似于MMU

课上用The Intel Pentium举例介绍
![Chapter 8 Main Memory__9](https://pub-e7c93c0b727d457c895b016a26707158.r2.dev/2026/11/Chapter%208%20Main%20Memory__9.png)

Pentium 结合了分段与分页机制，即**段页式内存管理**。CPU 生成逻辑地址后，按如下两阶段进行转换：

1. 段式转换：逻辑地址 $\to$ 线性地址
- **逻辑地址组成**：段选择符与段内偏移量
- **转换过程**：段选择符在段描述符表中查找对应段描述符，获取基地址后与偏移量相加生成线性地址

1. 页式转换：线性地址 $\to$ 物理地址

现代系统通常划分为四级或三级页表结构：

| global directory | middle directory | page table | offset |
| :---: | :---: | :---: | :---: |

最终将查找到的物理页框基地址与偏移量拼接，得到物理内存地址。
